# ⚡ 大学城充电桩监测

为广州大学城（华工大学城 C15 等区域）师生定制的充电桩实时可用性监测软件套件。  
手机打开 App 即可随时查看各个电桩空闲插口数，告别空跑排队。

## 📖 极简使用指南 (三步即可上手)

### 第一步：电脑提取 Token
1. 在 **Windows 电脑端微信** 中打开 **“智能充电”** 小程序并进入首页；
2. 双击打开下载的 `TokenExtractor-v1.0.0.exe`（绿色独立程序，无需安装）；
3. 点击界面中的 **“🚀 一键提取最新 Token”** 按钮；
4. 提示成功后，Token 已**自动复制到系统剪贴板**，通过微信（例如发给“文件传输助手”）发送给手机并复制。

### 第二步：手机设置 Token
1. 在 **安卓手机** 上安装并打开 `ChargingStationMonitor-v1.0.0.apk`；
2. 点击右上角 ⚙️ **设置** 按钮；
3. 点击 **“📋 粘贴剪贴板”**，再点击 **“💾 验证并保存 Token”**；
4. 显示验证通过后，Token 会永久保存在手机中，关机或退出后台都不会丢失。

### 第三步：随时查看充电桩空闲
1. 返回手机 App 主界面，即时查看华工大学城 C15 站的全部电桩状态：
   - 🟢 **绿色方块**：插口空闲（例如显示 `03 空闲`）；
   - ⚪ **灰色方块**：已被占用（例如显示 `01 占用`）；
2. 随时下拉屏幕或点击右上角 **🔄 刷新** 按钮获取最新状态；
3. **如遇 Token 失效**：若隔了数周 Token 过期，主界面顶部会出现红色提醒条，重复第一步在电脑提取一次并更新即可。

## ❓ 常见问题解答

- **Q: 电脑提取时提示“未检测到运行中的微信小程序”？**  
  A: 请先在电脑微信中真正点开“智能充电”小程序的独立窗口并进入首页，然后再点击提取。

- **Q: 手机 App 提示“Token 已失效”？**  
  A: 小程序登录凭据在一段时间后会自动过期。此时只需在电脑微信重新打开小程序，用提取器抓一次最新 Token 发给手机更新保存即可。

- **Q: 支持监控哪些充电桩？**  
  A: 当前版本默认针对华工大学城 C15 网点（包含 1号、2号、3号、4号充电桩，共 48 个充电插口）进行实时精准监控。
