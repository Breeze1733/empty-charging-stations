# 大学城充电桩监测

为华工大学城校区 C15 充电桩定制的实时空闲监测工具，手机打开 App 即可随时查看各个充电桩空闲插口数。

> 兼容提示：目前仅支持 Windows 电脑与 Android 安卓手机，macOS 与 iOS 暂时未兼容。

---

## 使用指南

### 第一步：电脑提取 Token
1. 在 Windows 电脑端微信中打开“智能充电”小程序并进入首页；
2. 下载并打开电脑提取工具 [TokenExtractor-v1.0.0.exe](https://github.com/Breeze1733/empty-charging-stations/releases/download/v1.0.0/TokenExtractor-v1.0.0.exe)（免安装绿色程序，约 19.7MB）；
3. 点击界面中的“一键提取最新 Token”按钮，程序会自动获取并写入系统剪贴板；
4. 通过微信（例如发送到文件传输助手）将 Token 发送给手机并复制。

### 第二步：手机安装 App 并保存 Token
1. 在安卓手机上下载并安装 [ChargingStationMonitor-v1.0.0.apk](https://github.com/Breeze1733/empty-charging-stations/releases/download/v1.0.0/ChargingStationMonitor-v1.0.0.apk)（手机 App，约 5.2MB）；
2. 打开 App，点击右上角设置按钮；
3. 点击“粘贴剪贴板”（或长按手动粘贴），再点击“验证并保存 Token”；
4. 显示验证通过后，Token 会保存在手机本地，关机或退出后台都不会丢失。

### 第三步：随时查看充电桩空闲
1. 返回 App 主界面，即可查看华南理工大学大学城校区 C15 的 1~4 号电桩（共 48 个插口）的空闲情况：
   - 绿色方块：插口空闲可用（例如显示“03 空闲”）；
   - 灰色方块：已被占用（例如显示“01 占用”）；
2. 随时下拉屏幕或点击右上角刷新按钮获取最新状态；
3. 如遇 Token 失效：若隔了数周 Token 过期，主界面顶部会出现提醒条，在电脑上重新提取一次并更新保存即可。

## 常见问题

- **Q: 电脑提取时提示“未检测到运行中的微信小程序”？**  
  A: 请先在电脑微信中真正点开“智能充电”小程序窗口并显示出首页，然后再点击提取按钮。

- **Q: 手机 App 提示“Token 已失效”？**  
  A: 微信小程序登录凭据在一段时间后会自动过期。此时只需在电脑微信重新打开小程序，用提取器提取一次最新 Token 发给手机更新即可。

- **Q: 支持监控哪些充电桩？**  
  A: 本工具针对华南理工大学大学城校区 C15 网点（包含 1号、2号、3号、4号充电桩，共 48 个充电插口）进行实时精准监控。
