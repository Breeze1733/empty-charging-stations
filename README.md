# 大学城充电桩监测

为华工大学城校区 C15 充电桩定制的实时空闲监测工具，手机打开 App 即可随时查看各个充电桩空闲插口数。

> 兼容提示：目前仅支持 Android 安卓手机，iOS 暂时未兼容。

---

## 使用指南（安装即用）

1. 在安卓手机上下载并安装 [ChargingStationMonitor-v1.0.0.apk](https://github.com/Breeze1733/empty-charging-stations/releases/download/v1.0.0/ChargingStationMonitor-v1.0.0.apk)（手机 App，约 5.2MB）；
2. 打开 App 即可直接使用！已内置 C15 充电桩默认 Token，无需任何配置，安装即用；
3. **视图切换**：顶栏右上角设有“切换视图”文字按钮，支持在“真实走廊地图视图”与“电桩卡片列表视图”之间无缝切换；
4. **实时状态查看**：
   - 绿色方块：插口空闲可用（例如“2-12 空闲”）；
   - 灰色方块：插口已被占用（例如“3-01 占用”）；
5. 随时下拉屏幕或点击右上角刷新按钮即可获取 1~4 号电桩（共 48 个插口）的最新空闲状态。
